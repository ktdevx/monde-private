# Monde 利用マニュアル

`monde` の利用者向けのマニュアルです。目的に合う章から読んでください。初めて使うときは、インストールの後に翻訳フローの章を読むと、新規翻訳と原文更新の手順を順に辿れます。

| 章 | 内容 |
| --- | --- |
| [インストール](install.md) | GitHub Releases からのアーカイブの入手、展開と配置、`monde --version` での確認、ソースからのビルド |
| [翻訳フロー](workflow.md) | 新規翻訳（`extract` → `init` → 翻訳 → `translate`）と原文更新（`extract` → `update` → 翻訳 → `translate`）の手順 |
| [コマンドリファレンス](commands.md) | 各サブコマンドの引数とオプション、統計の表示、診断メッセージ、終了コード |
| [既知の制限](limitations.md) | 初版で対応していない記法、YAML フロントマターの対応範囲、その他の制限 |

Monde の概要とクイックスタートは、リポジトリのルートの [README](../README.md) にあります。
