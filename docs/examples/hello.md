# Getting started

This is a *small* example document for the quick start.
It shows how monde translates Markdown text with
[GNU gettext](https://www.gnu.org/software/gettext/) translation files.

- Extract the text into a translation template.
- Create a translation file for your language.
- Translate the document with the translation file.

```sh
echo "Code blocks are not translated."
```
