# Product Overview

Monde は、Markdown 文書を gettext の翻訳テンプレート（`.pot`）と翻訳ファイル（`.po`）を介して翻訳するフローを支援する CLI ツール（コマンド名 `monde`）である。原文の構造と書式を壊さずに本文だけを訳し、原文が更新されても既存の翻訳を引き継げるようにする。翻訳作業そのもの（`.po` の編集）は、PO に対応した既存の翻訳プラットフォームやエディタに任せる。

- 発注元: Vabel ／ 著作権者: The Monde Authors ／ ライセンス: MIT License

## Core Capabilities

4 つのサブコマンドで翻訳フロー全体を覆う（初版はすべて 1 ファイル単位、コマンドライン引数のみ）。

| 操作 | コマンド | 入力 → 出力 |
| --- | --- | --- |
| テンプレート生成 | `monde extract` | `.md` → `.pot` |
| 翻訳ファイル作成 | `monde init` | `.pot` → `.po` |
| マージ | `monde update` | `.pot` + `.po` → `.po` |
| 翻訳済み Markdown 生成 | `monde translate` | `.md` + `.po` → `.md` |

- **ブロック単位の翻訳単位**: 段落・見出し・リスト項目・引用内の段落などを 1 つの msgid にする。強調・リンク・コードスパンなどのインライン記法は Markdown のまま msgid に含める。
- **翻訳対象の判定**: コードブロック、HTML ブロック、リンク先 URL・画像 URL は翻訳対象外。画像の alt は翻訳対象。
- **YAML フロントマター**: `--front-matter-keys` などのオプションで指定したキーの値だけを翻訳対象にする。
- **msgmerge 相当のマージ**: 完全一致の引き継ぎ、あいまい一致による fuzzy 付与、不要エントリの廃止（`#~`）。
- **翻訳者向け情報と統計**: 出現箇所を `#: file.md:行番号`、要素の種類を `#.` で出力する。翻訳率を表示する。

## Target Use Cases

- **新規翻訳**: `extract` → `init` → 翻訳者が `.po` を編集 → `translate`
- **原文更新**: 更新後の原文で `extract` → `update` で既存 `.po` とマージ → 差分を翻訳 → `translate`
- ドキュメントリポジトリで、翻訳済み Markdown を差分レビュー・バージョン管理しながら多言語化する。

## Value Proposition

- **バイト単位の書式保持**: 翻訳対象の文字列以外は原文をバイト単位でそのまま残す（リスト記号、強調記号の種類、空行、インデント、改行コード）。構文木から再生成しないため、差分が最小になる。
- **gettext エコシステムとの互換**: 生成する `.pot` / `.po` は GNU gettext の `msgfmt --check` を通る。既存の翻訳ツールをそのまま使える。
- **依存のない単一バイナリ**: 外部の実行時ライブラリに依存せず、Windows / macOS / Linux 向けのバイナリを GitHub Releases で配布する。

## Product Rules（挙動の既定）

- 未翻訳・fuzzy のエントリは原文を出力する。fuzzy の訳を採用するオプションを用意する。
- 同一文は 1 つの msgid にまとめる（将来、msgctxt で分けて訳すオプションを追加する可能性がある）。
- 翻訳率による出力の制御はしない（表示のみ）。
- CLI のヘルプ・エラーメッセージは英語。ドキュメント（README、利用マニュアル）は日本語。
- 入出力は UTF-8 のみ（BOM 付きも読み込める）。改行コード（LF / CRLF）は入力に合わせる。

## Versioning / Scope

- **初版（MVP）**: CommonMark（0.31.2）+ YAML フロントマター + 4 サブコマンド。
- **次の版**: GFM（表のセル単位の翻訳、タスクリスト、取り消し線、自動リンク）。脚注はさらに将来。
- **当面対象外**: 複数ファイル・ディレクトリの一括処理、設定ファイル、複数形エントリの本格対応（読み込みでエラーにしない程度のみ）、ライブラリとしての公開 API、パッケージマネージャーへの登録。

機能の分割と依存順は `.kiro/steering/roadmap.md` を参照する。
